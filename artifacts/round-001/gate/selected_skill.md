# Shopping Skill

> Active skill frozen by online randomized validation.

### 搜索查询构建 - 画像证据完整融合

- Applies when: 任务有约束且用户画像提供品牌偏好、历史搜索线索时
- Procedure:
  1. 从用户画像'最近 14 天搜索关键词'中提取所有属性要素（季节、材质、功能、风格、规格数值等）
  2. 将提取的全部属性词与任务指令中的显式约束组合为复合搜索查询
  3. 品牌偏好不直接融入搜索词，仅用于搜索结果出现多个匹配候选时的优先级排序
  4. 仅当任务指令明确要求某品牌时，才将品牌名称融入搜索查询
- Verify: 验证搜索结果首页是否出现同时匹配任务约束和用户搜索历史关键词的商品，且搜索查询词仅包含任务指令明确提及的属性
- Avoid: 仅提取部分搜索历史关键词遗漏关键属性，或将任务未明确要求的品牌偏好强行融入搜索词

### 购买决策 - 价格与定制约束协同验证

- Applies when: 任务包含明确价格上限约束且商品存在多个规格选项导致价格差异时，或任务指令包含'定制'需求且有明确预算约束且商品规格选项中存在含'定制'关键词的选项时
- Procedure:
  1. 识别所有与任务需求相关的规格选项
  2. 逐一检查各规格选项对应的具体价格
  3. 筛选出价格满足预算约束的选项
  4. 若任务包含定制需求，在商品规格选项中查找包含'定制'关键词的选项并优先选择
  5. 验证所选规格的价格是否在预算范围内
- Verify: 确认所选规格选项的价格严格小于任务指定的价格上限，且若任务含定制需求则规格名称包含'定制'关键词
- Avoid: 未验证规格价格即选择导致选择超出预算的规格选项，或仅关注功能属性匹配而忽略规格选项中的'定制'关键词

### 候选验证 - 规格选项精确匹配与深度检查

- Applies when: 商品详情页存在规格选择轴且需要点击特定规格选项时，或商品标题与任务核心约束表面不一致但商品类别匹配时
- Procedure:
  1. 从可点击元素列表中直接复制完整的规格选项文本，包括所有空格和特殊字符
  2. 使用该完整文本执行点击操作，不自行构造或修改
  3. 若商品标题与任务要求表面冲突，点击进入详情页检查规格选项是否包含符合要求的变体
  4. 确认规格选项明确标注符合任务要求的特征后再做购买决策
- Verify: 点击后规格状态显示'已选择'且 missing_option_axes 中不再包含该规格轴，或确认所选规格选项的关键属性与任务要求一致
- Avoid: 自行构造选项文本导致格式不匹配，或仅依赖商品标题判断匹配度而未检查规格选项变体

### 搜索查询构建 - 多功能约束完整提取

- Applies when: 任务指令包含多个并列功能要求（如多种病症防治、多种成分组合）或商品存在明确子类型区分（如风暖/灯暖）时
- Procedure:
  1. 识别任务指令中所有功能性要求关键词（病症名、成分名、功效词、子类型等）
  2. 将所有功能关键词与产品类别词组合为复合搜索查询
  3. 将子类型和功能特征词明确融入搜索查询，避免仅使用泛化类别词
- Verify: 验证搜索结果首页是否出现同时匹配所有功能关键词的商品
- Avoid: 仅提取单一功能属性进行窄化搜索，遗漏其他并列功能要求或子类型区分词

### 候选商品筛选 - 历史行为与预算协同

- Applies when: 多个候选均满足显式任务要求，且用户画像包含最近搜索关键词时，或商品存在多个满足功能需求的规格选项且任务有明确预算约束时
- Procedure:
  1. 从用户画像'最近14天搜索关键词'提取具体规格要素
  2. 优先选择标题或规格选项中包含这些规格要素的商品
  3. 列出所有满足核心功能需求的规格选项
  4. 优先筛选价格在预算上限内的选项
  5. 从符合预算的选项中选择最佳匹配规格
- Verify: 验证所选商品的关键属性是否与用户画像中的搜索历史关键词高度匹配，同时满足任务显式约束，且所选规格价格不超过预算上限
- Avoid: 忽略用户画像中具体规格搜索历史，仅依赖价格或商品属性丰富度做决策，或优先匹配历史搜索关键词而选择超出预算的选项
