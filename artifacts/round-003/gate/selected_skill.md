# Shopping Skill

> Active skill frozen by online randomized validation.

### 搜索查询构建 - 画像证据完整融合

- Applies when: 任务有约束且用户画像提供品牌偏好、历史搜索线索时
- Procedure:
  1. 从用户画像'最近 14 天搜索关键词'中提取所有属性要素（季节、材质、功能、风格、规格数值等）
  2. 将提取的全部属性词与任务指令中的显式约束组合为复合搜索查询
  3. 品牌偏好不直接融入搜索词，仅用于搜索结果出现多个匹配候选时的优先级排序
  4. 仅当任务指令明确要求某品牌时，才将品牌名称融入搜索查询
- Verify: 验证搜索结果首页是否出现同时匹配任务约束和用户搜索历史关键词的商品，且搜索查询词仅包含任务指令明确提及的属性
- Avoid: 仅提取部分搜索历史关键词遗漏关键属性，或将任务未明确要求的品牌偏好强行融入搜索词

### 购买决策 - 价格与定制约束协同验证

- Applies when: 任务包含明确价格上限约束且商品存在多个规格选项导致价格差异时，或任务指令包含'定制'需求且有明确预算约束且商品规格选项中存在含'定制'关键词的选项时
- Procedure:
  1. 识别所有与任务需求相关的规格选项
  2. 逐一检查各规格选项对应的具体价格
  3. 筛选出价格满足预算约束的选项
  4. 若任务包含定制需求，在商品规格选项中查找包含'定制'关键词的选项并优先选择
  5. 验证所选规格的价格是否在预算范围内
- Verify: 确认所选规格选项的价格严格小于任务指定的价格上限，且若任务含定制需求则规格名称包含'定制'关键词
- Avoid: 未验证规格价格即选择导致选择超出预算的规格选项，或仅关注功能属性匹配而忽略规格选项中的'定制'关键词

### 候选验证 - 规格选项精确文本与产品类型匹配验证

- Applies when: 商品详情页存在规格选择轴且任务指令或用户搜索历史包含多个属性约束时，或任务指令包含明确产品类型描述且规格选项存在多种产品类型变体时
- Procedure:
  1. 从任务指令中提取核心产品类型关键词和所有属性要素
  2. 逐一检查各规格选项的完整文本是否包含核心产品类型关键词和全部提取的属性词
  3. 排除仅含相似产品类型词但不含核心产品类型关键词的选项
  4. 优先选择同时包含核心产品类型关键词和所有属性关键词的选项
  5. 从页面可点击元素列表中逐字复制完整选项文本（包括所有空格、标点、特殊字符）
  6. 使用复制的精确文本执行点击操作，禁止自行构造、修改、省略或添加任何字符
- Verify: 确认所选规格选项的完整文本与页面显示的可选值完全一致（逐字符匹配），且包含任务指令明确提及的核心产品类型关键词和所有属性关键词，规格状态显示已选择
- Avoid: 自行构造或修改规格选项文本导致空格、标点或特殊字符不匹配，或选择含相似但不相同产品类型词的选项

### 搜索查询构建 - 多功能约束完整提取

- Applies when: 任务指令包含多个并列功能要求（如多种病症防治、多种成分组合）或商品存在明确子类型区分（如风暖/灯暖）时
- Procedure:
  1. 识别任务指令中所有功能性要求关键词（病症名、成分名、功效词、子类型等）
  2. 将所有功能关键词与产品类别词组合为复合搜索查询
  3. 将子类型和功能特征词明确融入搜索查询，避免仅使用泛化类别词
- Verify: 验证搜索结果首页是否出现同时匹配所有功能关键词的商品
- Avoid: 仅提取单一功能属性进行窄化搜索，遗漏其他并列功能要求或子类型区分词

### 候选商品筛选 - 商品类型与型号变体区分

- Applies when: 搜索结果中同一品牌存在多个型号变体且任务指令包含特定使用场景关键词时，或任务指令要求购买配件且搜索结果同时包含机身和配件商品时
- Procedure:
  1. 从任务指令中提取核心使用场景词（如遛娃、登机、旅行等）或识别核心商品类型（机身或配件）
  2. 识别搜索结果中同品牌商品的型号标识差异或商品类型关键词
  3. 优先选择标题同时包含品牌名、具体型号标识和任务场景词的商品
  4. 当任务需求为配件时优先选择标题或关键属性包含'配件'关键词的商品
- Verify: 确认所选商品标题包含任务核心场景关键词且型号标识与任务需求一致，或关键属性包含'配件'关键词
- Avoid: 仅依赖品牌匹配而忽略型号变体差异，或选择相机机身商品后依赖规格选项中的配件变体

### 规格选项选择 - 特定场景约束匹配

- Applies when: 任务指令包含明确尺码要求且商品规格选项中存在多个尺码变体时，或商品存在多个套餐类型选项且任务指令包含专业级要求时，或任务指令包含物流服务或风格特征描述词时，或商品存在多个满足预算的规格选项时
- Procedure:
  1. 识别任务指令中的场景约束关键词（尺码、套餐层级、物流服务、风格特征等）
  2. 在规格选项列表中逐项检查选项名称是否包含这些场景约束关键词
  3. 优先选择与任务要求完全匹配的规格选项
  4. 当多个选项均满足预算时，选择与任务描述核心特征最匹配的选项而非仅最低价
- Verify: 确认所选规格选项名称中包含任务要求的场景约束关键词，且规格状态显示已选择，价格在预算范围内
- Avoid: 忽略任务指令中的场景约束，或仅基于价格选择规格选项而忽略任务隐含属性匹配

### 候选商品筛选 - 关键属性与功能偏好覆盖验证

- Applies when: 用户画像包含明确的功能偏好列表且搜索结果存在多个候选商品时，或任务指令包含明确的商品属性要求且搜索结果页面显示商品关键属性列表时
- Procedure:
  1. 从用户画像'功能'偏好列表或任务指令中提取与当前任务相关的所有功能要求词和核心属性词
  2. 逐一检查候选商品的关键属性列表是否包含这些功能要求词和核心属性词
  3. 仅点击关键属性列表包含所有任务核心属性词的商品
  4. 优先选择关键属性覆盖全部功能要求的商品
- Verify: 点击前确认所选商品的关键属性列表包含用户画像功能偏好中所有相关功能词和任务指令中明确提及的所有核心属性词
- Avoid: 仅依赖搜索结果排序或商品标题进行筛选，未系统验证关键属性对功能偏好的覆盖度

### 候选验证 - 变体选项精确匹配验证

- Applies when: 任务指令包含具体型号与配件/组件组合要求，且搜索结果中存在标题看似匹配但规格选项不同的多个候选商品时
- Procedure:
  1. 从任务指令中提取核心变体要求（型号标识 + 配件/组件组合关键词）
  2. 对搜索结果中排名靠前的候选商品，依次点击进入详情页查看规格选项列表
  3. 检查每个商品的规格选项文本是否包含完整的型号与配件组合关键词
  4. 优先选择规格选项列表中存在精确匹配任务变体要求的商品
  5. 避免仅根据商品标题含配件关键词就做出选择
- Verify: 确认所选商品的规格选项列表中存在与任务型号和配件要求完全匹配的选项文本，且该选项处于可选状态
- Avoid: 仅依赖商品标题中的配件关键词进行筛选，未验证实际规格选项是否包含任务要求的精确变体组合
